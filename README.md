# Office Hub

Локальный установщик-каталог бесплатных программ вместо Microsoft Office и других продуктов Microsoft.
Открываете приложение, выбираете, что нужно, — оно ставит это через `winget`.

Всё на Windows, без установки чего-либо кроме Node.js: интерфейс открывается в браузере, сервер крутится в окне консоли.

## Что внутри

27 программ, сгруппированных по назначению, с рейтингом «сходство с MS Office» — сначала идут те, что максимально близко
работают с документами Word, Excel и PowerPoint:

| Программа | Вместо чего | .docx / .xlsx / .pptx |
|---|---|---|
| ONLYOFFICE Desktop Editors | Word, Excel, PowerPoint | родной формат, максимальное совпадение вёрстки |
| WPS Office | Word, Excel, PowerPoint + PDF | лента и диалоги как в MS Office |
| SoftMaker FreeOffice 2024 | Word, Excel, PowerPoint | полная запись и чтение |
| LibreOffice | Word, Excel, PowerPoint, Access, Publisher | читает и пишет (по умолчанию хранит в ODF) |

Плюс заметки вместо OneNote (Joplin, Obsidian, Logseq, Xournal++), PDF (PDF24, Sumatra), схемы вместо Visio
(draw.io, Inkscape), вёрстка вместо Publisher (Scribus), почта вместо Outlook (Thunderbird), базы вместо Access (DBeaver),
облако вместо OneDrive (Nextcloud, Seafile), GIMP, paint.net, VLC, 7-Zip, PeaZip, AutoHotkey, LyX, Zotero, calibre, Freeplane.

## Возможности интерфейса

- поиск по названию, описанию и форматам; фильтр по категориям; сортировка по сходству с MS Office
- кнопка «Проверить, что уже установлено» — сравнивает каталог с реальным списком Windows через `winget list`
- установка по одной и пакетом («в план» → «Установить выбранное»), обновление установленных
- живая панель вывода `winget` с возможностью отменить задачу
- переключатель «без окна установки» (флаг `--silent`)
- учебный режим: `node server.mjs --dry` показывает команду, но ничего не устанавливает

## Запуск

```bat
launch.bat
```

или вручную:

```bat
node server.mjs
```

Откроется `http://127.0.0.1:8765`. Порт меняется через переменную `PORT`. Сервер слушает только `127.0.0.1` и не доступен из сети.

## Требования

- Windows 10/11 с `winget` (App Installer)
- Node.js 18+ — внешних зависимостей нет, только стандартные модули

## Безопасность

- `/api/install` принимает строго ID из `catalog.json`: произвольную команду через него не передать, вызов идёт `spawn` без оболочки
- сервер привязан к `127.0.0.1`, CORS не настроен — страницей с другого сайта управиться нельзя
- установщик от имени администратора по-прежнему подтверждает Windows: для machine-wide инсталлеров всплывёт окно UAC

## Про форматы файлов и «ассоциации»

`.docx`, `.xlsx`, `.pptx` — открытая спецификация ECMA-376, и все четыре офиса выше их читают и пишут. Но Windows 11
не разрешает сторонним программам молча назначать приложение по умолчанию для расширения, поэтому в интерфейсе есть
ссылки на `ms-settings:defaultapps` и `ms-settings:appsdefaults` — выбрать редактор один раз приходится вручную.

Переносится в бесплатный офис хуже всего: макросы VBA, поля форм Word, сквозные нумерации и сложные комбинации плавающих объектов.
